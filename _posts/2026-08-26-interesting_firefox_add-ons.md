A living list of the Firefox add-ons that I use. I plan to update this post whenever I discover something new.

## Essential

- **Name:** uBlock Origin
- **Link:** [uBlock Origin](https://addons.mozilla.org/en-US/firefox/addon/ublock-origin/)
- **Use:** Blocking adverts across the web, and within YouTube. Chromium-based browsers have dropped support for this extension (as part of their Manifest V3 update), only providing a Lite version that's not nearly as comprehensive.

## Situational

- **Name:** IBM Equal Access Accessibility Checker
- **Link:** [IBM Equal Access Accessibility Checker](https://addons.mozilla.org/en-US/firefox/addon/accessibility-checker/)
- **Use:** Auditing web pages for accessibility issues against the Web Content Accessibility Guidelines (WCAG), directly in the browser. This produces a report that can then be used to better fix these issues. Covers WCAG 2.0-2.2 A, AA, but not AAA. Also covers the ISM Accessibility 

- **Extra resources** — I also use the following to help diagnose accessibility issues:
  - [BrowserStack Accessibility Testing](https://accessibility.browserstack.com/) — BrowserStack provides some great accessibility checks, and a helpful starting point.
  - [BrowserStack Performance](https://scanner.browserstack.com) — BrowserStack performance checking. One of my goals in building this website is to make it as fast as possible, similar to the basic sites of the '90s, but without dial-up. I'm hosting JavaScript (JS) and Cascading Style Sheets (CSS) files locally, and stripping them of unneeded content to minimise the site as much as possible. I'm also using Cloudflare for Content Delivery Network (CDN) performance.
  - [Infyways Accessibility Checker](https://www.infyways.com/tools/accessibility-checker) — Another accessibility checker, but this covers WCAG AAA, as well as other international standards (such as the Disability Discrimination Act 1992 (DDA)).
  - [Reddit thread on accessibility tools](https://www.reddit.com/r/webdev/comments/16yopk1/accessibility_tools_what_do_you_use_for_auditing/) — A Reddit thread discussing accessibility tools.
